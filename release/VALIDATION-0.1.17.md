# v0.1.17 验证记录

验证平台：Windows x64，适配目标 DeepSeek Harness 0.2.1-rc.2。

- 使用 pnpm 12.5.1 在隔离目录安装。CPU 依赖树为一个包，CUDA 为主包和 GPU 附属包两个包；构建脚本关闭。为避免重复从网络下载大型文件，本机测试把 GPU 的固定 Release URL 覆盖为对应本地 tgz，未改包内依赖声明；远端附件另外按 SHA-256 核验。
- GPU 组件 15 个 DLL 的哈希全部匹配；通过实际安装的依赖解析和挂载成功。重复挂载、损坏哈希、路径穿越拒绝测试通过。
- 发现并修复 pnpm 深目录造成的 Windows DLL 路径长度错误。最终运行时从专用短路径启动；复用、失败不发布就绪目录、临时目录清理测试通过。
- CUDA 自检实际执行检测、方向分类、识别三种 OCR 模型，三者首选提供程序均为 CUDAExecutionProvider，verifiedInference=true，warning=null。本机热缓存初始化约 4.3 秒，不代表所有设备的首次启动耗时。
- CPU 自检三种 OCR 模型仅使用 CPUExecutionProvider，运行时无 NVIDIA 目录。
- 宿主翻译接口、缓存范围、翻译提示词及部分响应处理共 5 项回归测试通过。模型使用固定测试响应，不消耗真实模型 tokens。
- 本次文档处理 EXE、Office 和 OCR 模块直接复用已验证的 0.1.16 二进制，没有改动解析与回填逻辑。0.1.16 的 18 种扩展名格式测试此前通过；本次未重复对每种格式调用真实翻译模型。
- 两个目录 YAML 条目通过社区目录 validateEntries 校验（0 错误）。公共搜索仍需社区审核与站点同步，尚未通过公共搜索入口执行端到端安装。
- 新增源文件、包清单和前端文件经过本地路径及凭据形状检查；二进制来自固定哈希的已审查发行附件。未加入用户文档、历史、数据库、日志或本机配置。
